## Research

Primary manufacturer directions were checked on November 24, 2026. Dilution, dwell times, application order and surface limits are specific to the named reference version. New products have no prices, checkout actions, offers schema or aggregate-review schema.

## Feedback

Public short excerpts appear only for four reference products: towel, pressure-washer gun, foam cannon and BLO AIR-S. Each excerpt preserves the reviewer name and links to the source. These are not TorqueBox orders. Sources showed initials, not profile photos, so no invented faces or customer identities are used. The other pages have an honest empty review state and an email feedback link. The email link does not submit or publish a review automatically.

## Application imagery
